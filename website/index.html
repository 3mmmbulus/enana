主要功能

一条命令安装，之后所有设置都在本机浏览器控制台里完成。

  • 按应用、按网站的规则

    为每个应用和网站选择直连、自动选择最快线路，或固定使用指定线路；自动选择只在明显更快时才切换，不会来回跳动。

  • 本机控制台

    安装后自动在浏览器中打开，中英文界面，手机和窄屏也能用；每次修改先校验再生效，出错自动回滚。

  • 连接质量监测

    实时速度与延迟、100 个内置测速目标、DNS 测速，以及最近 3 个月的流量统计；这些记录只保存在本机。

  • 多设备加密同步

    规则、服务器和偏好在本机端到端加密后再同步，enana.cc 只保存密文；在另一台电脑登录同一账号即可取回。

  • 一键部署自己的服务器

    填入 Debian 或 Ubuntu 服务器的地址和 SSH 登录方式，自动安装并在本机验证后加入列表；密码和私钥只在任务期间使用，不会保存。

  • 安全与隐私

    本机服务只接受本机访问；安装包和云端下发的内容都经过签名或哈希校验；删除服务器、查看凭据等敏感操作需要再次输入密码。

适合谁

  • AI 用户

    让常用的 AI 对话、写作和编程助手保持稳定连接，也可以让它们固定使用同一条线路。

  • 开发者

    代码托管、软件包与容器镜像下载、API 调用各自按规则选择线路；终端里的命令行工具也能使用同一套规则。

  • 远程团队

    每位成员在自己的电脑上安装，可以连接团队自己部署的服务器，异地开会和协作更顺畅。

安装后开通

如何开始

  1. 复制安装命令

    在「安装」一节选择你的系统，复制一行命令，粘贴到终端运行。

  2. 打开本机控制台

    安装完成后控制台会自动在浏览器中打开，用邮箱注册或登录 enana 账号。

  3. 设置规则，开始使用

    添加或导入自己的服务器，或开通专业版；为常用的应用和网站选好规则，打开总开关。

安装 enana

macOS · 在「终端」中运行

curl -fsSL https://install.enana.cc | bash

没有 curl？用 wget：

wget -qO- https://install.enana.cc | bash

Windows 10 / 11 · 在 64 位 PowerShell 中运行（预览版）

irm https://install.enana.cc/get.ps1 | iex

在命令提示符（cmd）中运行：

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://install.enana.cc/get.ps1 | iex"

安装完成后，本机控制台会自动在浏览器中打开。重复运行安装命令是安全的，已装好的部分会自动跳过。

每次都安装最新版本：安装脚本会先读取 https://install.enana.cc/dl/manifest.json，核对版本号和校验值。

如果你安装的是 2.3.16 之前的版本，请重新运行一次安装命令，之后的升级才会校验签名。

常见问题

enana 是什么？

enana 是运行在 macOS 和 Windows 上的桌面网络管理工具：一条命令安装，之后在本机浏览器控制台里为应用和网站设置规则、查看连接质量，让 AI 服务和开发工具保持稳定、快速。

支持哪些系统？

macOS（Apple 芯片和 Intel），以及 Windows 10 2004 及以上版本和 Windows 11（x64、ARM64）；Windows 版目前为预览版。两个系统使用同一个控制台。

怎么安装和升级？

在「安装」一节复制对应系统的命令，粘贴到终端运行即可。升级时再运行一遍安装命令，或在终端输入 enana self-update。

免费版和专业版有什么区别？

免费版包含联网规则、本机控制台、连接质量监测、加密同步和一键部署自己的服务器。专业版在此基础上提供官方加速线路和更多同时在线设备，4 USDT / 月起，安装后在本机控制台开通。

我的数据会上传吗？

流量记录和连接日志只保存在你的电脑上。服务器和规则在同步前会先在本机端到端加密，enana.cc 只保存密文，看不到服务器地址和密码；SSH 登录密码和私钥从不同步，同步也可以在设置里关闭。

怎么卸载？

在终端输入 enana uninstall。卸载会删除全部本机数据，需要保留的内容请先在控制台导出备份。
